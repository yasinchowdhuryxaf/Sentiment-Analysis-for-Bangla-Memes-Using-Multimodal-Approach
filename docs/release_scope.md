# Rights and release scope

## Included with owner approval

- Recruiter-focused documentation and high-level diagrams.
- Selected aggregate results reported in the thesis.
- Original `MEME_DATA_Excel.xlsx` and all 276 supplied meme images, copied without modification.
- Small synthetic samples, four new walkthrough notebooks, and limited demonstration modules.

## Withheld

- Original experiment notebooks and their saved outputs.
- Meta classifier fusion implementation, associated training code, feature construction, and detailed architecture.
- Full training orchestration, fitted models, credentials, and model checkpoints.
- The thesis PDF and any corpus records absent from the supplied local collection.

The public code was written as a separate companion. It does not change the original research files or claim to reproduce their reported scores. Excluded code is not embedded in notebook outputs, images, or repository history added by this release.
